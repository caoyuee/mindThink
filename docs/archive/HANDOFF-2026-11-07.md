## M0-3 · B3 自动备份保留策略与清理 ✅（JS 侧全绿；Rust 未编译验证）

### 目标
- 设置页可配置「最多保留备份数」`backupKeepMax`（默认 20，范围 1–100）。
- 每次保存生成 `<原名>.backup-<stamp>` 时间戳备份（stamp 由 `formatBackupStamp` 生成：`YYYY-MM-DDTHH-MM-SS-mmmZ`，无 `:`/`.`，字典序即时间序）。
- 保存后按 `backupKeepMax` 自动裁剪老备份（`pruneBackups` → Rust `list_backup_files` + 纯函数 `selectBackupsToDelete` + Rust `delete_files`）。
- 红线：只允许操作 `<原名>.backup-*` 命名的文件，杜绝误删；裁剪失败仅 warn + toast，不阻断保存。

### 改动文件
共享（两端字节一致）：
- `src/core/backup.ts`（新增）— 纯函数：`formatBackupStamp` / `isBackupFileName` / `sortBackupPathsDesc` / `selectBackupsToDelete` / `basename`。
- `src/tests/backup.spec.ts`（新增）— 5 个纯函数测试。
- `src/stores/config.ts`（**parity 允许差异**：tauri 版额外保留 `recentFiles`）— 新增 `backupKeepMax: number`、`BACKUP_KEEP_MIN=1`、`BACKUP_KEEP_MAX=100`、`normalizeBackupKeepMax()`，默认 20，load/save 归一化。
- `src/views/SettingsView.vue` — 新增 `settings.backupKeepMax` 数字输入 + 提示。
- `src/i18n/locales/{zh-CN,en,zh-TW,de}.json` — 新增 `settings.backupKeepMax` / `settings.backupKeepMaxHint`（tauri 语言包在保留 `menu.*` 块基础上补齐）。

Tauri 专属（被 parity 允许差异）：
- `tauri-spike/src/core/tauri-file.ts` — 新增 `tauriListBackupFiles(path)`、`tauriDeleteFiles(paths)`。
- `tauri-spike/src/core/file.ts` — `backupFile()` 改用 `formatBackupStamp(new Date())`；新增 `pruneBackups(path, keep)`（list → select → delete）。
- `tauri-spike/src/stores/mindmap.ts` — `save({backup})` 调用 `pruneBackups(documentPath, config.userConfig.backupKeepMax)`（try/catch → `logger.warn` + `toast.warn`）。修复既有 bug：`t`/`toast` 此前在 store 中未声明 → 改为 `const t = i18n.global.t.bind(i18n.global)`（直接取应用 i18n 实例，测试无 app 上下文也能用）。
- `tauri-spike/src-tauri/src/commands.rs` — 新增 `list_backup_files`（扫父目录 `<原名>.backup-` 前缀、降序）、`delete_files`（拒绝文件名不含 `.backup-` 的路径，跳过不存在项）。
- `tauri-spike/src-tauri/src/lib.rs` — 导入并注册 `list_backup_files`、`delete_files` 到 `generate_handler!`。
